## Project summary
XPower wants a simple Household Tariff Analysis prototype that allows household customers to upload electricity usage data, calculate bills under different tariff schemes, compare costs and savings, visualise usage/bill information, and use the system through a friendly UI.

## Project constraints
- Duration: 5 weeks
- Budget: $10,000
- Prototype technologies: Python-based implementation with CSV/Excel data support

## Required tariff models
- Flat Rate
- Time-of-Use (Peak / Off-Peak / Shoulder)
- Tiered / Block tariff
