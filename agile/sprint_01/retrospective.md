# Sprint 1 Retrospective

**Status:** Complete

## What Went Well

- The GitHub repository and project structure were set up early.
- Team members were able to work on different tasks using separate branches.
- The Project Charter, WBS and WBS Dictionary were completed.
- Data Import and tariff calculations were implemented successfully.
- Automated testing helped identify problems early.
- The current 22 tests are all passing.

## What Could Be Improved

- Some Sprint task statuses were not updated when the work was completed.
- A few planning documents used function names that later changed during development.
- Branches should be kept updated with `main` to reduce differences before merging.

## What We Will Improve in Sprint 2

- Keep the Sprint backlog updated as tasks are completed.
- Continue using branches and Pull Requests before merging into `main`.
- Keep documentation consistent with the actual code.
- Continue testing features as they are developed instead of leaving testing until the end.
