# Project Charter – XPower Household Tariff Analysis

**Project Duration:** 5 weeks  
**Budget:** $10,000  
**Project Team:** Mohit, Dev, Pedro and Lakshay  
**Status:** Approved

## Project Purpose

The purpose of this project is to develop a simple Household Tariff Analysis prototype for XPower. The system will help household customers upload their electricity usage data, calculate their bill using different tariff options and compare the results to identify possible savings.

## Project Objectives

The project aims to:

- Allow users to upload electricity usage data from CSV or Excel files.
- Calculate electricity costs using Flat Rate, Time-of-Use and Tiered tariffs.
- Compare tariff results and show possible savings.
- Display electricity usage and bill information using simple charts.
- Provide a simple interface that can be used without technical knowledge.
- Test the main Python functions to make sure the calculations work correctly.

## Project Scope

### In Scope

- CSV/Excel data import.
- Flat Rate, Time-of-Use and Tiered tariff calculations.
- Bill calculation and tariff comparison.
- Usage and bill visualisation.
- Cost-saving suggestions.
- Simple user interface.
- Python functions and unit testing.

### Out of Scope

- Connection to real XPower billing systems.
- Real customer payments.
- Live smart-meter integration.
- Production deployment.

## Key Stakeholders

| Stakeholder | Main Interest |
|---|---|
| **XPower** | A working prototype that meets the project requirements. |
| **Household Customers** | An easy way to understand and compare electricity costs. |
| **Development Team** | Successfully plan, develop, test and deliver the project. |

## Project Constraints

- The project must be completed within **5 weeks**.
- The available budget is **$10,000**.
- The system is being developed as a **working prototype**, not a full production system.
- Team members need to work together and complete their assigned tasks on time.

## Success Criteria

The project will be successful if the prototype can import electricity data, calculate and compare the required tariffs, display useful results through a simple interface, and the required testing and project documentation are completed.
