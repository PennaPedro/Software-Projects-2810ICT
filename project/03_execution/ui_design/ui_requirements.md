# UI Requirements

**Status:** Done

The XPower interface should be simple and easy to use so a household customer can complete the main analysis without technical knowledge.

## Wireframe Flow

The agreed wireframes follow four main screens:

1. **Upload Electricity Data**
   - Upload CSV or Excel electricity usage data.
   - Show the required data format and supported file types.

2. **Configure Tariff**
   - Choose Flat Rate, Time-of-Use or Tiered tariff.
   - Enter tariff rates, time periods, thresholds and optional fixed fee.

3. **Calculate and Compare**
   - Show the imported data summary.
   - Calculate the available tariff options.
   - Compare estimated bills and highlight the lowest-cost result.

4. **Results and Savings**
   - Show the best tariff option and possible savings.
   - Display electricity usage information and bill breakdown.
   - Show charts and a simple cost-saving suggestion.

## Design Requirements

- Keep the interface clear and uncluttered.
- Use simple labels and instructions.
- Display clear error messages when uploaded data or tariff values are invalid.
- Keep the main process in a simple step-by-step flow.
- Present tariff results in a way that is easy to compare.
